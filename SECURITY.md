# Security policy

This policy covers the software Archery New Zealand runs or maintains in the `archerynz` GitHub organisation, including Nock (nock.archery.org.nz).

## Reporting a problem

Email **ictsystems@archery.org.nz** with:

- what you found and where (a link or the steps to reproduce it), and
- how to contact you if we have questions.

Please don't open a public GitHub issue for a security problem, and don't access, change, or keep anyone else's data while checking.

## What to expect

- We reply within 5 working days to say we have your report.
- We aim to fix Critical and High problems within 7 days, Medium within 30 days, and Low at the next routine update.
- We tell you when it's fixed. If you'd like to be credited, say so and we'll name you.

We are a volunteer-run national sports organisation, so there is no bug bounty.
